Cara Menghubungkan ke Google Sheets

Opsi 1: Menggunakan SheetDB (Paling Cepat)

  • Tempel link API SheetDB kamu (contoh: https://sheetdb.io/api/v1/...) lalu klik Hubungkan SheetDB.
  • Pastikan di pengaturan SheetDB izin Read, Create, Update, Delete sudah diaktifkan.
  • Sediakan 1 kolom yang nilainya unik (misal ID) dan pilih kolom tersebut di menu Kolom Kunci agar proses edit/hapus tepat sasaran.

Opsi 2: Menggunakan Google Cloud OAuth 2.0

  1. Buka Google Cloud Console, buat project baru, lalu aktifkan Google Sheets API di menu Library.
  2. Di menu OAuth consent screen, pilih External, isi nama aplikasi, dan masukkan email kamu di bagian Test users.
  3. Di menu Credentials, buat OAuth client ID bertipe Web application dan tambahkan URL GitHub Pages kamu di Authorized JavaScript origins.
